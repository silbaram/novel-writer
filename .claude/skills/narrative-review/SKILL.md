# Narrative Review

라이트노벨/웹소설 프로젝트의 스토리 바이블·챕터 초안·연속성을 검토하는 절차 가이드다. `story-bible-reviewer`(바이블 검토), `novel-style-guardian`(문체 검수), `continuity-keeper`(연속성 추적)가 이 스킬을 참조한다.

---

## 검토 심각도 정의

모든 검토 결과는 세 단계로 분류한다.

| 단계 | 표기 | 의미 | 처리 규칙 |
|------|------|------|----------|
| **Critical** | `[Critical]` | 독자 몰입을 근본적으로 훼손하거나 Canon 충돌이 발생하는 문제 | 해당 Phase 산출물을 finalizing 전에 반드시 수정 |
| **Should** | `[Should]` | 흔들리는 지점. 방치하면 누적될 수 있으나 즉시 차단하지는 않음 | 수정 권고. 저술가 판단에 따라 수용 가능 |
| **Nice** | `[Nice]` | 사소한 윤문·개선 제안. 독자 경험을 조금 더 높일 수 있음 | 선택적 반영 |

## 섹션 1: 스토리 바이블 검토

`story-bible-reviewer`가 사용하는 8개 검토 축의 절차와 판정 기준이다.

### 축 1 — 로그라인 명확성

**확인 절차:**
1. 로그라인에서 주인공·목표·장애물을 각각 밑줄 친다
2. 세 요소가 모두 한 문장 안에 있는지 확인한다
3. 장르와 톤이 로그라인에서 느껴지는지 확인한다

**판정 기준:**

| 판정 | 조건 |
|------|------|
| Pass | 주인공·목표·장애물이 한 문장에 모두 있다 |
| Revise | 한 요소 누락 또는 불명확 |
| Fail | 이야기가 무엇인지 파악되지 않는다 |

**흔한 Critical 패턴:**
- `[Critical]` "한 소년이 강해지는 이야기다" — 장르·장애물·특수성 없음
- `[Critical]` 로그라인에 목표 달성 여부가 이미 서술됨 — 결말 스포일러

---

### 축 2 — 주인공 욕망과 결핍

**확인 절차:**
1. 주인공 카드에서 "욕망"과 "결핍" 항목을 각각 읽는다
2. 둘이 서로 긴장 관계에 있는지 확인한다: 결핍이 욕망 달성을 방해하는가?
3. 결핍이 외부 상황에만 있고 내면 심리에는 없는지 확인한다

**흔한 패턴:**
- `[Critical]` 욕망만 있고 결핍이 없음 — 외부 장애물만 처리하는 단조로운 성장
- `[Should]` 결핍이 "가난·고아·약함" 등 외부 상황뿐 — 상황 해결 시 캐릭터 완성, 이야기 정지
- `[Should]` 욕망과 결핍 사이에 관계가 없음 — 극적 긴장 미발생

---

### 축 3 — 세계관 규칙 일관성

**확인 절차:**
1. `world_rules.md`의 각 규칙에 "왜 이야기에 필요한가"가 서술되어 있는지 확인한다
2. `magic_system.md` 또는 `system_rules.md`에 **한계와 비용**이 정의되어 있는지 확인한다
3. 규칙 간 모순이 없는지 확인한다

**흔한 패턴:**
- `[Critical]` 마법/능력에 한계가 없음 — 갈등 해소가 너무 쉬워짐
- `[Should]` 세력(`factions.md`)에 목표가 없이 이름만 나열 — 갈등의 실체 없음
- `[Nice]` 세계관 규칙이 이야기와 연결 설명 없이 나열만 됨

---

### 축 4 — 갈등 강도

**확인 절차:**
1. 갈등 카드에서 4개 층위(외부·내부·대인·사회)를 각각 읽는다
2. 각 층위가 서로 연결되는지 확인한다
3. 시즌 전체를 유지할 만큼 복잡한지 확인한다

**흔한 패턴:**
- `[Critical]` 내부 갈등 없음 — 행동은 있지만 캐릭터 성장 없음
- `[Should]` 갈등이 너무 쉽게 해소될 것처럼 설정됨
- `[Should]` 사회적 갈등 없음 — 세계관이 배경으로만 머뭄

---

### 축 5 — 관계의 유용성

**확인 절차:**
1. `relationships.md`의 각 관계에 "표면 관계 / 숨겨진 긴장"이 분리되어 있는지 확인한다
2. 각 관계가 최소 하나의 갈등 층위와 연결되는지 확인한다
3. 제거해도 이야기에 영향 없는 관계가 있는지 확인한다

---

### 축 6 — 시즌 씨앗 분리

**확인 절차:**
1. `season_seeds.md`에서 시즌 1 씨앗의 Canon 상태가 `[LOCKED]` 또는 `[DRAFT]`인지 확인한다
2. 시즌 2 이상이 `[CANDIDATE]` 또는 `[DRAFT]`인지 확인한다
3. 시즌 씨앗에 플롯 비트·챕터 배치가 포함되어 있지 않은지 확인한다

---

### 축 7 — Canon 상태 품질

**확인 절차:**
1. `[LOCKED]` 항목이 핵심 설정에만 집중되어 있는지 확인한다 (너무 많으면 유연성 손실)
2. `[CANDIDATE]` 항목이 바이블 본문에서 확정 사실처럼 서술되지 않았는지 확인한다
3. `open_questions.md`에 미확정 항목이 체계적으로 기록되어 있는지 확인한다

**흔한 패턴:**
- `[Critical]` `[CANDIDATE]` 설정이 본문에서 확정 사실로 서술됨
- `[Should]` 모든 설정이 `[LOCKED]` — 이후 저술 유연성 없음

---

### 축 8 — Phase 3·4 준비도

**Phase 3 진행 가능 조건 (모두 충족):**
- [ ] 로그라인 Pass
- [ ] 주인공 욕망·결핍 모두 정의됨
- [ ] 세계관에 한계 있는 마법/시스템 정의됨
- [ ] 4개 갈등 층위 중 최소 3개 정의됨
- [ ] 시즌 1 씨앗이 `[LOCKED]` 또는 `[DRAFT]`로 존재
- [ ] `open_questions.md` 존재하고 비어 있지 않음

**판정:**
- **Pass:** 위 조건 모두 충족
- **Conditional Pass:** 하나 미충족, 수정 제안 포함 시 Phase 3 진행 가능
- **Fail:** 로그라인 Fail / 주인공 욕망·결핍 모두 없음 / 세계관 규칙 전무

---

## 섹션 2: 챕터 문체 검수

`novel-style-guardian`이 챕터 초안을 검수할 때 사용하는 절차다.

### 검수 전 준비

초안을 읽기 전에 반드시:
1. `{slug}/seasons/sNN/season_bible.md`의 톤 키워드를 확인한다
2. 해당 챕터의 시점 인물의 캐릭터 파일을 읽는다
3. 챕터 초안의 `<!-- author-note -->` 저자 노트(챕터 목표·감정 변화)를 읽는다

저자의 의도를 모른 채 표면만 지적하면 과교정이 된다.

### 8개 검수 항목 절차

**항목 1 — 시점(POV)**
- 씬 구분(`---`) 없이 시점 인물이 바뀐 경우 → `[Critical]`
- 시점 인물이 알 수 없는 정보가 본문에 등장한 경우 → `[Critical]`
- 1인칭 서술자 어조가 캐릭터 설정과 불일치 → `[Should]`

**항목 2 — 대사**
- 태그에 감정이 서술된 경우(`"...", 그가 슬프게 말했다`) → `[Should]`
- 독자를 위한 세계관 설명이 대사에 그대로 들어간 경우(브리핑 대사) → `[Should]`
- 대화가 5줄 이상인데 중간 행동 묘사 없음 → `[Nice]`

**항목 3 — 설명 과다(Infodump)**
- 행동·대사 없이 300자 이상 설명 블록이 단독 존재 → `[Should]`
- 챕터 첫 문단이 순수 세계관/과거 설명 → `[Should]`

**항목 4 — 감정선**
- "그는 슬펐다" 같은 감정 직접 명명 → `[Should]`
- 저자 노트의 "감정 변화"와 본문 감정 흐름 불일치 → `[Critical]`
- 챕터 시작과 끝에서 감정 변화가 없음 → `[Should]`

**항목 5 — 장면성**
- 씬이 끝났는데 아무것도 달라지지 않음 → `[Should]`
- 씬 초반에 공간·시간·분위기 앵커 없음 → `[Nice]`

**항목 6 — 리듬**
- 긴장 씬에서 문장이 평균보다 짧아지지 않음 → `[Nice]`
- 수동태 남발 → `[Should]`
- 한 문단에 동일 어휘 3회 이상 반복 → `[Nice]`

**항목 7 — 챕터 엔딩**
- 마지막 단락에 훅이 없음 → `[Critical]`
- 다음 챕터 예고만으로 끝남(이번 챕터 무게 없음) → `[Should]`

**항목 8 — 장르 톤**
- 시즌 바이블 톤 키워드와 챕터 분위기 불일치 → `[Should]`
- 클리셰 의존 (장르 공식 기계적 반복) → `[Should]`

### 피드백 작성 원칙

- **원문 인용 필수:** 문제 구절을 원문 그대로 인용 후 대안 제시
- **과교정 금지:** 챕터당 수정 제안 5~10건 상한
- **저자 노트 참조:** 저술가의 의도를 확인한 뒤 피드백. 의도를 모른 채 지적하지 않는다

## 섹션 3: 연속성 추적

`continuity-keeper`가 사용하는 추적 절차다.

### 캐릭터 상태 추적

챕터 완료마다 `character_state_table.md`를 갱신한다.

갱신 항목:
- 현재 위치
- 신체 상태 (부상·회복)
- 감정 상태 (직전 챕터 종료 기준)
- 소지품·능력 변화
- 관계 변화 (서술 기준)
- 알고 있는 정보 (이후 챕터에서 모르는 척 하지 않도록)

**경고 조건:**
- `[Critical]` 이전 챕터에서 설정된 부상이 다음 챕터에서 언급 없이 사라짐
- `[Should]` 인물이 아직 알 수 없는 정보를 아는 것처럼 행동함

---

### 타임라인 추적

`timeline.md`에 챕터 단위로 기록한다.

| 챕터 | 서사 내 시간 | 주요 사건 | 인물 위치 |
|------|------------|----------|----------|

**경고 조건:**
- `[Critical]` 같은 시간에 인물이 두 장소에 있을 수 없는 경우

---

### 복선 추적

`foreshadowing_tracker.md` 테이블 형식:

| 복선 이름 | 심은 챕터 | 심는 방식 요약 | 예정 회수 시즌/챕터 | 상태 |
|----------|---------|--------------|-------------------|------|
| | | | | 미회수 / 회수 완료 / 주의 |

**갱신 시점:**
- **심기:** 챕터 저자 노트의 "사용한 복선" 항목에서 추출 → 상태 `미회수`로 추가
- **회수:** 챕터 저자 노트의 "회수한 복선" 항목에서 추출 → 상태 `회수 완료`로 변경
- **이월 감지:** 시즌 바이블의 "이번 시즌에서 회수할 복선"이 시즌 마지막 챕터 후에도 `미회수`이면 → `[Critical]` 경고

---

### 시즌 간 연속성

시즌 경계에서 수행한다.

**시즌 종료 시 체크리스트:**
- [ ] 시즌 핵심 질문이 답해졌는가?
- [ ] `foreshadowing_tracker.md`에서 이번 시즌 회수 예정 복선이 모두 `회수 완료`인가?
- [ ] `character_state_table.md`가 피날레 직후 상태로 갱신되었는가?
- [ ] 다음 시즌 훅이 심어졌는가?

**시즌 시작 시:**
- 이전 시즌 연속성 파일을 `continuity/s{NN}_archive/`로 이동
- `character_state_table.md`는 이전 시즌 종료 상태를 그대로 이어받아 새 시즌 시작
- 미회수 복선은 새 시즌 추적 테이블로 이월

## 섹션 4: 시즌 구조 검토 (Phase 5 단계 2 전용)

`story-bible-reviewer` Mode A 결과를 받은 뒤 오케스트레이터가 이 섹션을 기준으로 `narrative-review`를 호출한다. **`season-planner`가 설계한 시즌 구조의 서사 완성도**를 7개 축으로 평가한다.

### 검토 대상 파일

- `{slug}/03_season_plan.md`
- `{slug}/seasons/s01/season_bible.md`
- `{slug}/02_story_bible.md` (Canon·금지 클리셰 확인용)
- `{slug}/characters/protagonist.md` (인물 아크 기준선)

---

### 축 1 — 시즌 핵심 질문 강도

**확인 절차:**
1. `season_bible.md`의 "시즌 핵심 질문"을 읽는다
2. 질문이 이야기 전체를 20챕터(또는 해당 분량) 내내 끌고 갈 만큼 구체적이고 강렬한가?
3. 시즌 종료 시 이 질문이 답해지는가?

**판정 기준:**

| 판정 | 조건 |
|------|------|
| Pass | 질문이 구체적이고 시즌 내에서 명확히 답해진다 |
| Should | 질문이 너무 광범위하거나, 답이 모호하게 처리될 위험이 있다 |
| Critical | 핵심 질문이 없거나 시즌 내에서 답해지지 않는다 |

---

### 축 2 — 3막 챕터 배분 균형

**확인 절차:**
1. `03_season_plan.md`의 챕터 배분표를 읽는다
2. 각 막의 챕터 비율을 계산한다
3. 권장 범위: 1막 20~30% / 2막 45~55% / 3막 20~30%

**판정 기준:**

| 판정 | 조건 |
|------|------|
| Pass | 각 막이 권장 범위 내에 있다 |
| Should | 한 막이 권장 범위를 10% 이상 벗어난다 |
| Critical | 3막이 전체의 10% 미만이거나 1막이 40% 초과다 |

**흔한 패턴:**
- `[Should]` 2막이 60% 이상 — 위기가 늘어지고 해소가 급함
- `[Critical]` 3막이 1~2챕터뿐 — 피날레가 압축되어 독자 불만족

---

### 축 3 — 주인공 내적 성장 곡선

**확인 절차:**
1. 주인공 카드의 "결핍"과 "내적 성장 방향"을 읽는다
2. 시즌 아크에서 주인공의 내적 전환점이 최소 1회 명시되어 있는가?
3. 시즌 종료 시 결핍이 완전 해소가 아닌 "한 발자국 이동" 수준으로 처리되는가? (단권 완결 과도 해소 주의)

**판정 기준:**

| 판정 | 조건 |
|------|------|
| Pass | 내적 전환점 1회 이상 명시, 적절한 수준으로 성장 |
| Should | 전환점이 외부 사건으로만 처리되고 내면 심리 변화가 없다 |
| Critical | 주인공 내적 변화가 시즌 아크에 전혀 반영되지 않는다 |

---

### 축 4 — 복선 심기/회수 실현 가능성

**확인 절차:**
1. `season_bible.md`의 복선 계획을 읽는다
2. 각 복선이 심기는 챕터와 회수 챕터 사이에 충분한 간격이 있는가? (최소 3챕터 이상 권장)
3. 회수 챕터가 시즌 종료 전에 배치되어 있는가? (마지막 챕터에 회수가 몰리면 위험)
4. 심은 복선 수가 현실적으로 관리 가능한가? (단권 기준 5~10개 권장)

**판정 기준:**

| 판정 | 조건 |
|------|------|
| Pass | 모든 복선이 시즌 내에서 회수 가능하고 배치가 자연스럽다 |
| Should | 일부 복선 회수가 마지막 2챕터에 집중되어 있다 |
| Critical | 시즌 내 회수 불가능한 복선이 있거나, 복선 수가 20개 초과다 |

---

### 축 5 — 피날레 메커니즘 납득성

**확인 절차:**
1. `season_bible.md`의 피날레 메커니즘을 읽는다
2. 피날레 해소가 로그라인·갈등 설계에서 논리적으로 도출되는가?
3. 피날레에 사용되는 요소가 이전 챕터에서 충분히 복선으로 준비되었는가?
4. `02_story_bible.json`의 `forbidden_cliches`에 해당하는 해소 방식을 쓰고 있지 않은가?

**판정 기준:**

| 판정 | 조건 |
|------|------|
| Pass | 피날레가 기존 설정에서 논리적으로 도출되고, 복선이 준비되어 있다 |
| Should | 납득은 가능하나 준비 복선이 약하다 |
| Critical | 뜬금없는 능력·인물·정보로 해소된다 ("갑자기 강해짐" 등) |

---

### 축 6 — 시즌 엔딩 훅 강도

**확인 절차:**
1. 시즌 마지막 챕터의 엔딩 훅을 읽는다
2. 단권 완결의 만족감과 다음 시즌 기대감이 동시에 있는가?
3. 훅이 새로운 질문을 열어두는가? (기존 갈등의 단순 연장이 아닌)

**판정 기준:**

| 판정 | 조건 |
|------|------|
| Pass | 완결 만족 + 다음 시즌 기대감이 공존한다 |
| Should | 완결감만 있고 다음 시즌 연결이 약하다 (또는 반대) |
| Critical | 훅이 없어 시즌이 그냥 끝나는 느낌이다 |

---

### 축 7 — 금지 클리셰 노출 위험

**확인 절차:**
1. `02_story_bible.json`의 `forbidden_cliches` 목록을 읽는다
2. 시즌 아크에서 해당 클리셰가 발생할 위험이 있는 챕터·장면을 식별한다
3. 위험 징후가 있으면 구체적 챕터 번호와 함께 경고한다

**판정 기준:**

| 판정 | 조건 |
|------|------|
| Pass | 금지 클리셰 노출 위험 없음 |
| Should | 한 가지 클리셰가 발생할 가능성이 있다 |
| Critical | 금지 클리셰가 피날레 또는 핵심 전환점에 그대로 사용된다 |

### 시즌 구조 종합 판정

| 판정 | 조건 |
