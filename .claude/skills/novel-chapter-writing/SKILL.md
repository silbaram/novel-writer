# Novel Chapter Writing

라이트노벨/웹소설의 챕터 초안을 저술하는 절차 가이드다. `chapter-novelist`가 이 스킬을 참조한다. 스타일 리뷰 이후의 문장 퇴고와 최종본 생성은 `chapter-prose-reviser`와 `novel-prose-revision`이 담당한다.

---

## 집필 절차

### 단계 0 — 씬 카드 분해

본문을 쓰기 전에 챕터 플랜을 2~4개 씬으로 분해한다.

| 씬 | 목표(무엇이 달라지는가) | 갈등/장애 | 전환(씬 끝의 변화) | 감각 앵커 |
|----|-------------------------|-----------|----------------------|-----------|
| 1 | | | | |

- 챕터 플랜의 주요 사건을 모두 씬에 배정한다.
- 주요 사건은 장면 안에서 실시간으로 일어나야 한다. 플랜을 위에서 아래로 요약 서술하지 않는다.
- 시간 경과 때문에 요약·몽타주로 처리할 사건이 있으면 이유를 저자 노트에 기록한다. 챕터당 1회 이내만 허용한다.
- 씬 카드는 저자 노트의 `씬 카드` 섹션에 그대로 남긴다.

### 단계 1 — 오프닝 작성

챕터의 첫 문장 또는 첫 단락은 독자를 씬 안으로 끌어들이는 앵커다.

**허용 오프닝 유형:**
- **씬 직입:** 행동·감각이 이미 진행 중인 지점에서 시작
- **내면 갈등:** 시점 인물의 생각·감정이 직접 열리는 순간
- **대화:** 맥락 없이 대사로 시작해 독자를 끌어당기는 방식

**금지:**
- "이번 장에서는 ~를 다룬다" 같은 메타 선언
- 세계관 설명 블록으로 시작하는 인포덤프 오프닝
- 직전 챕터 요약으로 시작하는 recap 오프닝

**감각 앵커 포함:** 오프닝 안에 독자가 공간·시간·분위기를 파악할 수 있는 감각 이미지 1~2개를 심는다.

---

### 단계 2 — 씬 구성

각 씬을 작성할 때 다음 원칙을 지킨다.

**씬 목적 원칙:**
- 모든 씬은 끝날 때 무언가 달라져야 한다 (정보·감정·관계·위치 중 하나 이상)
- 씬 전후로 아무것도 변하지 않으면 해당 씬을 삭제하거나 다른 씬에 통합한다
- 챕터 플랜을 위에서 아래로 낭독하는 요약체를 금지한다. 사건은 단계 0의 씬 카드에 배정된 장면 안에서 실시간으로 일어난다

**시점 유지:**
- 챕터 플랜에 지정된 시점 인물을 씬 내내 유지한다
- 시점 전환이 필요하면 반드시 `---` 씬 브레이크로 경계를 만든다
- 시점 인물이 알 수 없는 정보를 서술자가 서술하지 않는다

**작품 고유 화자 유지:**
- `{slug}/P02_bible/voice_profile.md`가 있으면 1인칭 내레이션, 비유, 묘사 문단의 마지막 반응에 반영한다.
- 외부 사건 설명만 길게 이어져 화자 고유의 해석이 사라지면 실패로 본다.
- 새 장소·인물·사물 묘사는 감각 연결 패스 후, 가능하면 voice profile의 사고방식에 맞는 농담·판단·불편함으로 닫는다.

**설명 분산:**
- 세계관·배경 설명은 행동과 대사 사이에 분산한다
- 300자 이상의 순수 설명 블록을 단독으로 두지 않는다
- 인물이 이미 아는 사실을 독자에게 알려주기 위해 내독자에게 설명하는 대사를 쓰지 않는다

**속도 조절:**
- 긴장·전투·추격 씬 → 짧은 문장, 단문 위주
- 감정·회상·대화 씬 → 여유 있는 호흡, 적절한 길이
- 공간·사물·상황 설명 씬 → 단문-중문-단문 흐름. `있었다`·`했다`·`였다` 종결이나 명사형 단문을 반복해 목록처럼 끊지 않는다
- 새 장소·인물·사물 첫 묘사 → 먼저 POV 인물의 감각이나 행동을 통과시킨다. `무엇이 있었다`보다 `코끝에 닿았다`, `손바닥에 걸렸다`, `고개를 들자 보였다`, `그가 움직이자 드러났다`를 우선한다

---

### 단계 3 — 대사 작성

**캐릭터 고유 어투 유지:**
대사를 쓸 때마다 해당 인물의 캐릭터 파일의 "말투 특징"과 "대사 예시"를 확인한다. 독자가 따옴표 없이도 누가 하는 말인지 알 수 있어야 한다.

**태그 원칙:**
- `"...", 그가 말했다` — 허용
- `"...", 그가 슬프게 탄식하며 말했다` — 금지. 감정은 대사 전후 행동 묘사로 전달한다

**대화 중 행동 묘사:**
대화가 5줄 이상 이어지면 중간에 표정·몸짓·주변 환경 묘사를 끼워 넣는다. 대화만 나열되면 독자의 시각적 상상이 멈춘다.

**브리핑 대사 금지:**
독자를 위한 세계관 설명을 인물 대사에 그대로 넣지 않는다. 인물은 이미 알고 있는 사실을 새삼 설명하지 않는다.

---

### 단계 4 — 감정선과 복선

**감정 표현 원칙:**
- "그는 슬펐다" 같은 직접 명명 대신 신체 반응·행동으로 표현한다
  - 예: "그는 슬펐다" → "그는 말을 잇지 못하고 시선을 바닥으로 내렸다"
- 챕터 시작과 끝의 시점 인물 감정이 다르게 끝나야 한다

**복선 처리:**
- 챕터 플랜의 "복선 사용" 항목에 명시된 복선을 독자가 의식하지 못하게 자연스럽게 심는다
- "회수할 복선" 항목의 복선은 이 챕터에서 회수한다
- 심거나 회수한 복선은 저자 노트에 반드시 기록한다

**Canon 확인:**
- `[LOCKED]` 설정을 변경하지 않는다
- `[CANDIDATE]` 설정을 확정 사실처럼 서술하지 않는다. 불확실한 경우 `(설정 확인 필요)` 표기 후 계속 작성한다

---

### 단계 5 — 챕터 엔딩 훅 작성

챕터 마지막 단락은 반드시 다음 챕터를 읽고 싶게 만드는 훅을 포함한다.

| 훅 유형 | 설명 | 예시 형태 |
|--------|------|---------|
| **질문형** | 새로운 의문을 남긴다 | 마지막 문장이 설명 없이 끝나는 모호한 발견 |
| **반전형** | 예상을 뒤집는 사실이 드러난다 | 직전까지의 전제를 무너뜨리는 한 줄 |
| **감정형** | 인물이 강한 감정적 결단을 내린다 | 결심·포기·각성의 내면 선언 |
| **위기형** | 직접적 위험이나 갈등 직전에서 끊는다 | 위협의 등장 또는 씬 직전에서 cut |

**금지:**
- 다음 챕터 예고 문장으로만 끝나는 엔딩 ("다음 챕터에서 그는 …을 만나게 된다")
- 아무 여운 없이 평범하게 닫히는 엔딩

---

### 단계 6 — 장면 밀도 패스

엔딩 훅까지 포함한 전체 초안을 끝낸 뒤 반드시 한 번 더 읽으며 장면/사물/인물 묘사가 너무 기능적으로 끝난 곳을 보강한다. 목표는 웹소설 속도를 유지하면서 핵심 장면의 체감 밀도를 15~25% 높이는 것이다. 문예체로 늘리거나 수식어를 과도하게 붙이지 않는다.

**보강 대상:**
- **새 장소:** 시각 외 감각(소리·냄새·온도·촉감) 1개 이상과 POV 인물의 감정/신체 반응 1개 이상을 넣는다. 가능하면 코끝 → 발밑/손 → 귀 → 시선 → 주인공의 기억/농담 순서처럼 몸의 이동을 따라 묶는다.
- **새 인물:** 외형, 습관적 동작, 시선/태도 중 2개 이상을 첫 등장부에 심는다. 직업·역할 설명만으로 끝내지 않고, 행동 중간에 외형 정보를 끼워 넣는다.
- **핵심 사물:** 기능 설명 외에 질감, 무게감, 소리, 손에 닿는 느낌, 정서적 연상 중 1개 이상을 붙인다. 사물이 `있다`고 말하기보다 POV 인물이 만지거나 바라보는 순간으로 보여준다.
- **핵심 상황 설명:** 사실 전달 뒤에 POV 필터를 붙인다. 설명 문단 3개 중 최소 1개는 피로, 불안, 기대, 안도 같은 감정 또는 신체 반응을 포함한다.

**리듬 조정:**
- 단문 4개 이상이 연속되면 의도된 긴장/코미디 박자인지 확인한다.
- 긴장 장면이 아니면 단문-중문-단문 흐름으로 호흡을 조절한다.
- 설명 문단이 `A였다. B였다. C였다.`처럼 툭툭 끊기면, 같은 공간·사물에 속한 정보는 한두 문장으로 묶고 마지막에 POV 인물의 농담, 불편함, 신체 반응 중 하나로 닫는다.
- 한 문단 안에서 `있었다`·`했다`·`였다`·`났다` 같은 동일 종결이나 같은 어휘가 3회 이상 반복되면 표현을 바꿔 호흡을 부드럽게 만든다.
- `~고`, `~며`, `~는데`, `~자`, `~다가` 같은 연결어미를 묘사 문단에 섞어 감각과 행동을 한 호흡으로 이어 준다.
- **연결어로 붙인 체크리스트 금지:** `~고`, `~며`, `~자`로 문장을 붙였더라도 각 절의 중심이 냄새, 소리, 조명, 먼지처럼 사물/공간에 머물면 실패다. 하드 게이트에 걸린 첫 묘사 문단을 고칠 때는 코끝, 발밑, 손바닥, 귀, 시선, 기억, 농담, 불편함 중 최소 3개를 자연스럽게 골라, 항목처럼 나열하지 말고 POV 인물의 몸·시선·판단 흐름 안에 녹인다.
- **위치 주어 반복 점검:** 한 묘사 문단 안에서 `바닥은`, `앞쪽에서는`, `머리 위에는`, `창구 너머에는`, `벽에는`, `그 안에서`, `대기석은`, `배지는`, `신발 앞코는` 같은 위치/사물 주어가 3회 이상 이어지면 위치 주어를 줄이고 `몸을 움직이자`, `고개를 들자`, `손을 짚자`, `귀가 늦게 열리자`, `시선이 창구 쪽으로 넘어가자` 같은 POV 동작을 연결축으로 삼는다.
- 효과음·한 단어 문장·한 줄 문단은 장면의 결정적 박자에만 둔다. 평범한 묘사 정보라면 주변 감각이나 행동과 같은 문단에 묶는다.
- 대화가 5줄 이상 이어지면 중간에 인물의 손, 시선, 자세, 주변 소리 중 하나를 끼워 넣는다.

**고치지 않는 단문:**
- 개그 타이밍, 충격, 당황한 인식, 깨달음, 대사 핑퐁을 만드는 단문은 유지한다.
- 수정 대상은 정보 나열용 단문이다. 예: `냄새가 있었다. 등불이 있었다. 먼지가 반짝였다.`

**금지:**
- Canon이나 사건 순서를 바꾸는 보강
- 시점 인물이 알 수 없는 정보로 분위기를 설명하는 보강
- 형용사·부사를 늘려 문장을 무겁게 만드는 보강

---

### 단계 7 — 묘사 연결 패스

장면 밀도 패스 후, 새 장소·인물·사물 묘사 문단을 다시 읽고 감각이 늘어난 만큼 장면이 부드러워졌는지 확인한다. 감각 정보가 많아졌지만 연결축이 없으면 장면 밀도 보강이 아니라 감각 체크리스트다.

**확인 기준:**
1. 감각 정보가 단순히 추가되었는가, 아니면 POV 인물의 몸과 시선으로 연결되었는가?
2. 문단을 한 줄 요약했을 때 `냄새/소리/빛/물건 목록`이 되는가?
3. 위치 주어가 바뀔 때마다 POV 인물의 동작이 따라오는가?
4. 묘사 마지막에 인물의 판단, 기억, 농담, 불편함 중 하나가 남는가?

문제가 있으면 감각을 더 추가하지 말고, POV 인물의 몸·시선·판단이 문단을 끌고 가도록 다시 연결한다.

회귀 테스트 기준은 `style-guides/lightnovel-style-guide.md`의 "회귀 테스트 예시 — 감각 체크리스트 문단"이다. 원문이 `코끝 → 몸을 움직임 → 귀에 들림 → voice profile에 맞는 기억/농담/판단 → 고개를 듦 → 시야` 같은 연결축으로 바뀌지 않으면 묘사 연결 패스를 통과하지 못한 것이다.

```markdown
## 저자 노트 (내부용)

### 씬 카드
{단계 0의 씬 분해표 + 요약 처리한 사건과 그 이유}

### 챕터 목표
{이 챕터에서 달성하려는 서사적·감정적 목표}

### 등장인물
{이 챕터에 등장한 인물 목록 — 이름과 씬 역할}

### 감정 변화
{시점 인물의 감정 이동: 시작 감정 → 종료 감정}

### 사용한 복선
{이 챕터에서 심은 복선 — 이름 및 심는 방식}

### 회수한 복선
{이 챕터에서 회수한 복선 — 이름 및 회수 방식}

### 장면 밀도/연결 패스
{보강한 장면 / 추가한 감각·정서 요소 / POV 몸·시선 연결축 확인 / voice profile 반영 여부 / 리듬 조정 여부}

### 퇴고 주의 지점
{의도적으로 유지해야 하는 단문 / 개그 타이밍 / 복선 문장 / 바꾸면 안 되는 대사 / 훅 문장}

### 다음 챕터 연결
{이 챕터 마지막 상태에서 다음 챕터가 어떻게 이어지는가 — 훅 포함}
```

저자 노트는 독자에게 보이지 않는 내부 메타데이터다. `novel-editor`가 통합 원고 생성 시 제거하고, `continuity-keeper`가 복선·연속성 갱신에 활용한다.

최종본(`{CCC}_final.md`)은 스타일 리뷰와 퇴고를 거친 뒤 `chapter-prose-reviser`가 생성한다.

## 금지 패턴 빠른 참조

`style-guides/lightnovel-style-guide.md` 섹션 8(금지 사항)의 핵심을 요약한다.

| 금지 패턴 | 대안 |
|----------|------|
| 감정 직접 명명 ("그는 슬펐다") | 신체 반응·행동으로 표현 |
| 태그 감정 서술 | 대사 전후 행동 묘사 |
| 브리핑 대사 | 행동·씬을 통한 자연스러운 노출 |
| 인포덤프 블록 | 설명을 행동·대사 사이에 분산 |
| 핵심 사건 요약 서술 | 씬 카드에 배정하고 실시간 장면으로 극화 |
| 시점 오염 | 씬 브레이크로 시점 전환 경계 명시 |
| 목적 없는 씬 | 씬 전후 변화를 확인하고 없으면 삭제 |
| 장면/사물/인물 묘사 부족 | 초안 후 장면 밀도 패스로 감각·정서·리듬 보강, 묘사 연결 패스로 POV 연결축 확인 |
| 감각 체크리스트 | 감각을 더 추가하지 말고 POV 몸·시선·판단으로 연결 |
| 툭툭 끊기는 설명 문단 | 관련 정보를 묶고 단문-중문-단문 흐름으로 조정 |
| 상태문 나열 (`있었다/였다/났다`) | POV 감각·행동 중심 문장으로 전환 |
| 효과음·한 줄 문단 과다 | 결정적 박자만 남기고 나머지는 주변 행동과 묶기 |
| 훅 없는 챕터 엔딩 | 4가지 훅 유형 중 하나 반드시 사용 |
| Canon 무단 변경 | `[LOCKED]` 항목 확인 후 집필 |

## 에러 처리

| 상황 | 처리 |
|------|------|
| 챕터 플랜이 없거나 해당 섹션 비어 있음 | 오케스트레이터에 Phase 4 미완료 보고, 집필 대기 |
| `[LOCKED]` 설정과 챕터 플랜 충돌 | 오케스트레이터와 `story-bible-planner`에게 보고, 집필 중단 |
| 레퍼런스에 없는 사실이 필요한 경우 | `(설정 확인 필요)` 표기 후 계속 작성, 저자 노트에 기록 |
| 스타일 리뷰 피드백이 직접 들어옴 | 최종본을 작성하지 않고 오케스트레이터에 `chapter-prose-reviser` 라우팅 필요를 보고 |
